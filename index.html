📋 Đọc đơn lên KiotViet

✕ Đóng

1. Dán tin nhắn đơn hàng

Sao chép nguyên tin nhắn khách gửi qua Zalo rồi dán vào ô dưới. Dán nhiều đơn một lúc cũng được.

2. Mã hàng + số lượng

Chưa có đơn. Dán tin nhắn ở bước 1 để bắt đầu.

Mẹo: trên KiotViet, gõ hoặc dán từng mã hàng vào ô tìm hàng khi tạo đơn, nhập số lượng, rồi bấm vào dòng để gạch dòng đã nhập. Nút "Chép bảng" cho ra 2 cột Mã hàng – Số lượng, dán thẳng vào file Excel nhập đơn.

⚙️ Quản trị sản phẩm

✕ Về bảng giá

Bạn chưa có quyền quản trị

Chỉ người có quyền chỉnh sửa trang mới thêm, sửa, xoá hoặc ẩn sản phẩm được.

☁️ Nơi lưu bảng giá:

Bấm "Lưu & cập nhật bảng giá" sẽ ghi file index.html mới lên kho GitHub chứa web. GitHub Pages hoặc Cloudflare Pages (nối với kho này) tự cập nhật web sau khoảng 1 phút. Mã truy cập chỉ lưu trên trình duyệt của máy này, không nằm trong web.
